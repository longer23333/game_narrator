# GameNarrator Android

当前版本 0.55.0 提供项目级精确字幕、审阅、离线质检、逐分镜配音、专业混音和 GPU 调色；播放头关键帧现支持缩放、旋转、水平/垂直位置、0–100% 透明度和 0–200% 音量，导出时按帧或音频采样插值。

Android 10+ 完全本地运行的独立剪辑应用，不依赖桌面端或局域网后端。

当前 0.27.0 阶段将字幕、图片、视频、音频素材和部分特效提示接入真实 Media3 导出。字幕支持静态和逐字动态烧录；图片和视频素材支持位置、缩放及 GPU 叠加，视频按所属分镜时间出现；音频素材按所属分镜时间点与原声并行混合，并支持独立音量和等功率淡入淡出；高对比、暖色、冷色、黑白、缩放、旋转和片段边界淡入淡出会转换为实际视频 Effect。

素材库支持名称、类型和标签检索；切片合集支持跨项目收集片段、持久化排序、移除和一键生成独立剪辑项目。

素材库支持图片、视频、音频的完整预览；剪辑面板可把当前片段中间帧派生为 PNG 封面素材，自动添加“派生/封面”标签并进入素材库。

特效模板库可保存当前分镜的特效提示组合，并应用到任意分镜；应用时与已有提示合并且不重复，模板保存在本地数据库。

分镜文案勾选“与下一片段交叉转场”后，导出会在片段边界通过 Media3 视频合成器做平滑 alpha 交叉淡化；同一时间线可包含多个交叉转场，并与视频素材叠加共同工作。

镜头文本搜索页在当前项目内建立端侧索引，对镜头名称、字幕、解说和特效提示做离线相似度检索，可一键定位分镜或把单个镜头导出为独立 MP4（画面、字幕、素材与声音效果真实渲染）。图像相似度检索需要端侧视觉模型，当前未安装时明确提示。

设置页提供设备、ABI、CPU、内存、存储和媒体编码器诊断，可复制或分享不含凭据与媒体内容的报告，并能在严格的应用私有目录边界内安全清理缓存。

新增“AI 设置 · 用量 · 模型检查”页：只展示已安装可运行引擎，未安装的转写/视觉/文案模型明确标注；可查看离线 TTS 音色、项目/版本/导出/素材用量与数据库大小。首次启动提供使用引导，设置页可重开引导和查看与版本一致的更新公告。应用关键事件写入 JSONL 结构化运行日志（最多 2000 条 / 1 MiB），可查看、导出和清空。

分镜解说可使用手机已安装的中文 Android TTS 引擎生成本地 WAV，自动登记到素材库、放入对应分镜并参与最终混音；缺少中文语音包时会明确提示安装系统语音数据。

平台导入入口支持手机端 HTTP/HTTPS 音视频直链下载，提供进度、取消、临时文件与原子完成、媒体类型校验、64 MiB 存储安全余量，并可自动建立剪辑项目。还支持格式偏好筛选（MP4/MOV/WEBM/MKV/音频）以及解析常见网页中的 og:video、video/source 媒体直链；Bilibili 登录助手（WebView 官方页、Cookie 仅内存、关闭即清除）与 cookies.txt 内存会话已接入 read/cv 与 opus 专栏提取；需要登录的网页视频直链仍需后续端侧合规登录解析引擎。

设置页支持导出 `.gnproject.json` 项目归档并通过系统文件选择器恢复为新项目。归档保存当前时间线、分镜文案、最多 100 个版本快照、素材引用、混音与视觉参数；媒体大文件不重复嵌入，恢复后仍需原 URI 可访问。

版本历史支持长按重命名，以及从任意快照建立独立项目分支。分支复制快照片段与适用的素材放置参数并创建“分支起点”，不会修改原项目。

版本历史还支持与当前时间线一键对比（新增、移除、内容变化），并可按“只补缺失”或“覆盖同名片段”合并历史版本；合并前状态进入撤回历史，可随时恢复。

关键帧曲线编辑器可逐属性编辑关键帧的时间、数值与插值曲线（线性、缓入、缓出、缓入缓出），支持在编辑器中直接添加关键帧；保存后 Media3 导出按曲线插值真实生效。

导出提供真实 720p/30 FPS、1080p/30 FPS、原画质预设，以及高度 240–2160、帧率 12–120 或跟随源、码率 1–100 Mbps 的自定义参数。自定义设置会记忆，实际使用的预设写入导出任务历史。

当手机确实存在 HEVC 编码器时，导出列表会增加 HEVC 1080p 高压缩预设；平台模板提供 1080×1920/30 FPS 竖屏和 1920×1080/60 FPS 横屏画布，并通过 Media3 真实缩放适配。

源监视器支持按真实视频帧率逐帧前后步进、播放/暂停、0.5×–2×预览速度、标记入点/出点，以及外接键盘 J/K/L；入出点编辑进入撤回和版本历史。

时间线波形使用 MediaExtractor + MediaCodec 在手机端解码当前片段入点到出点的真实 PCM，支持常见整数和浮点 PCM 输出并按时间桶计算峰值，不再使用压缩包大小近似声音强弱。

音轨控制将音频分为原声、解说配音、音乐/音效，分别支持项目级 Mute/Solo。存在任意独奏时只导出已独奏且未静音的轨道；状态随项目归档和版本分支保留。

首页项目卡片支持长按重命名、事务化复制和移入回收站。设置页可恢复项目；永久删除需要再次确认，只清理应用内工程、版本、任务和引用关系，不删除手机原媒体或已导出 MP4。

新增“剪辑任务”页与项目流水线六阶段（素材导入、镜头修剪、分镜文案、配音与素材、版本检查、视频渲染）；阶段状态持久化，重启后可继续。导出、下载与 TTS 支持真实停止，取消或失败不会覆盖已完成的终态。

新增“一键自动继续”：阶段面板可为缺失解说的分镜批量生成离线 TTS 配音并自动进入导出；可随时取消，任务状态不覆盖终态。

时间线新增轨道分配：片段可分配到 V1 主视频轨或 A1 纯音频轨；A1 片段按时间轴位置只混入声音，不占主画面，轨道信息随项目归档与版本分支保留。

轨道分配新增 V2 视频叠层轨：片段可作为全屏叠加视频在时间轴对应位置覆盖到主画面之上，音频静音；V1 主视频轨与 A1 纯音频轨仍按原语义工作。

MOV/ProRes 已通过内置 arm64 FFmpeg 支持并在真机验证；端侧转写/视觉/文案模型已打包并可在 AI 设置页直接测试；正式签名发行与真机逐页截图对照需要用户提供签名密钥和 Android 真机。

模型也可直接打包：把 whisper-*.bin、vision-*.onnx、text-*.onnx 放入 android-app/app/src/main/assets/models/ 后构建，首次启动会自动复制到 getExternalFilesDir("models")，无需再跑 install-models.ps1；Whisper 转写还需 whisper-cli 引擎与模型放在同一目录，体积会直接计入 APK。

模型部署细节、Whisper 下载与 Android 版 whisper-cli 编译方式见 docs/ANDROID_MODELS.md。

已提供 release 签名构建脚本与本地测试密钥 APK（android-app/keystore 已加入 .gitignore）；生产正式签名仍应使用用户自有密钥，真机端到端验证需连接 Android 设备。

导出提供快速、标准和高质量三档真实 H.264 目标码率预设，并在设备不完全支持请求参数时启用编码器回退。

重叠交叉转场、完整特效模板、端侧转写/视觉/文案模型仍在后续阶段，界面会明确提示，不会显示为已完成。

快捷命令：

- scripts\update-android-ai-context.cmd：生成根目录 ANDROID_AI_CONTEXT.md，可直接提供给 AI。
- scripts\build-android-apk.cmd：运行 Lint、单元测试和 Debug 构建，并将带版本号的 APK 输出到 dist。

也可在 android-app 目录运行 gradlew.bat assembleDebug，原始 APK 位于 app\build\outputs\apk\debug\app-debug.apk。
