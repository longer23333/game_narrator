# 本地账号、后台管理与云端迁移

## 当前实现

- H2 文件数据库继续作为离线桌面版的本地数据库，Flyway V28 新增正式账号、会话、逐用户 AI 配置/用量、管理审计和云同步清单。
- Flyway V30 使用 `user_external_asset` 隔离每个账号的素材库收藏、归档和可见范围；同一物理素材允许在本机安全复用，但其他账号不能通过素材 ID 直接预览或删除。
- 未登录时使用固定匿名账号，行为与旧版本一致；登录后任务、项目与媒体元数据按账号归属。
- 第一个正式注册账号自动成为管理员，后续账号默认为普通用户。管理员入口为 `/admin.html`。
- 密码使用 PBKDF2-SHA256（随机盐、210000 次）保存，会话只保存 SHA-256 摘要。API Key 使用 AES-256-GCM 加密，主密钥可通过 `GAME_NARRATOR_SECRET_KEY` 注入；离线模式会在数据目录生成本机密钥。

## 大视频与存储边界

数据库只保存项目、路径、哈希、大小、状态和同步位置，不保存视频二进制。40GB 视频必须使用流式上传/分片上传，并进入本地磁盘或 S3/OSS/COS/MinIO 等对象存储，不能一次读入 JVM 内存。`cloud_sync_item` 是后续断点续传、秒传、校验和失败重试的清单。

## 转为云端时

1. 将 H2 数据源替换为 PostgreSQL，并对 V28 SQL 做 PostgreSQL 兼容验证。
2. 把认证服务部署到 HTTPS 域名，桌面端继续使用 Cookie 或 Bearer Token。
3. 实现对象存储分片上传，完成后仅把 object key、ETag、SHA-256 与大小写回数据库。
4. 同步项目 JSON、成片和素材时读取 `cloud_sync_item`，客户端只缓存代理文件/缩略图；源文件按需下载。
5. 云端主密钥应放在 KMS/Secret Manager，不复制本地 `local-master.key`。

当前版本提供可迁移的数据模型和管理接口，但尚未配置真实云服务器与对象存储，因此不同电脑登录同一账号不会自动获得视频文件；这需要部署云端服务后启用同步执行器。

## 管理中心能力

管理中心 `/admin.html` 采用成熟后台常见的“总览 + 领域列表 + 审计”结构：

- 总览展示用户、项目、任务、素材、存储、当月 AI 成本和待同步数量，并提供近 14 天 Token 趋势、用户/项目状态分布及最近管理操作。
- 用户管理支持搜索、筛选、分页、CSV 导出、角色与状态调整、存储配额、API 月预算以及强制撤销会话。
- 项目、AI 用量、云同步和审计日志统一提供中文字段、状态标识、筛选与导出。
- 存储管理展示磁盘容量、受管源视频、产物占用和最大源视频，并复用安全清理服务处理过期临时文件。
- 所有管理接口都要求已登录的管理员身份；存储检查与清理同样在执行任何文件系统操作之前完成权限验证。
