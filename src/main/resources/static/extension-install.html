GAME NARRATOR

安装素材浏览助手

连接后可把当前 Bilibili 页面中的推荐或搜索结果同步为待确认素材候选；扩展不会自动下载内容。

平台视频 URL 仍由 GameNarrator 统一交给 yt-dlp 解析；需要登录时请由用户主动上传临时 cookies.txt。

① 下载扩展 ZIP
2

解压下载的 ZIP

在下载文件上点击右键，选择“全部解压”。记住解压后的文件夹位置。不要直接双击 ZIP 内的文件。

3

打开扩展管理页面

把下面地址复制到浏览器地址栏并回车。

chrome://extensions
4

加载扩展文件夹

打开右上角“开发者模式” → 点击“加载已解压的扩展程序” → 选择刚才解压的文件夹。应当选择里面能直接看到 manifest.json 的那一层。

5

连接 GameNarrator

回到 GameNarrator，点击浏览器右上角拼图图标 → GameNarrator 浏览器助手 → “连接当前网站”。看到“连接成功”即完成。

完成后可在公共素材库读取 Bilibili 推荐和搜索候选。

浏览器安全规则要求首次安装必须由用户确认，网页无法代替点击。
