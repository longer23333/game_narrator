# GameNarrator 浏览器助手

这是项目配套的 Chrome/Edge Manifest V3 扩展。它只负责连接 GameNarrator，并把当前 Bilibili 首页推荐或搜索结果登记为“待确认权利”的素材候选；不会读取或上传 Cookie，也不会自动下载视频。

平台视频 URL 统一由 GameNarrator 后端通过 yt-dlp 解析。平台要求登录时，用户可在导入页主动上传 Netscape `cookies.txt`；后端只保留当前平台域名的临时 Cookie，下载完成或一小时后删除。

## 安装或升级

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向本目录。
4. 如果以前安装过旧版，点击扩展卡片上的“重新加载”。
5. 打开 GameNarrator 页面，点击扩展图标，再点击“连接当前网站”。

扩展升级后会恢复已连接站点的桥接脚本；已打开的 GameNarrator 页面需要刷新一次。

## 同步 Bilibili 候选

1. 在同一个浏览器中正常登录 Bilibili。
2. 在 GameNarrator 公共素材库读取首页推荐，或输入关键词读取搜索结果；也可以在 Bilibili 搜索页通过扩展弹窗勾选结果。
3. 确认只处理本人作品、已获授权或平台许可使用的素材。
4. 将选中结果同步为素材库候选。

扩展只同步标题、BV 号、作者、封面、来源链接和页面可见指标。候选记录不会触发下载；用户确认权利后，下载仍走统一的 yt-dlp 导入流程。首页推荐最多同步 30 项，十分钟内不会重复读取。
