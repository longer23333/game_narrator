# GameNarrator 浏览器助手

## Bilibili 专栏提取（1.5.0）

在 GameNarrator 的“Bilibili 账号连接”区域粘贴专栏或动态链接，即可通过当前已登录的 Bilibili 官方会话提取标题、作者、正文和图片。正文会显示在分镜导入界面，图片会登记为待确认素材；确认拥有使用权后，才能进入下载、抠图和剪辑流程。扩展不会保存账号密码，也不会把 Cookie 写入日志或素材元数据。

这是项目配套的 Chrome/Edge Manifest V3 扩展，提供两项能力：

1. 经用户授权，把当前视频平台的临时登录状态交给已连接的 GameNarrator，用于解析和下载用户有权使用的内容。
2. 在 Bilibili 搜索页面读取当前可见的视频卡片，勾选后批量同步为公共素材库候选项。
3. 打开 GameNarrator 公共素材库时，使用当前 Bilibili 登录会话读取首页推荐并只保存候选记录；不会自动下载。
4. 在公共素材库搜索时，后台使用同一登录会话打开 Bilibili 搜索页，读取当前关键词的搜索结果并同步候选记录。

扩展升级后会根据已连接站点自动恢复桥接脚本；不需要每次升级后重新连接。已打开的 GameNarrator 页面仍需刷新一次，以加载新版页面脚本。

## 安装或升级

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向本目录。
4. 如果以前安装过旧版，点击扩展卡片上的“重新加载”。
5. 打开 GameNarrator 页面，点击扩展图标，再点击“连接当前网站”。

## 批量同步 Bilibili 搜索结果

1. 在同一个浏览器中正常登录 Bilibili。
2. 打开 Bilibili 搜索页面并等待视频卡片加载完成。
3. 点击 GameNarrator 扩展图标。
4. 勾选要同步的结果，并选择素材类型。
5. 确认只处理本人作品、已获授权或平台许可使用的素材。
6. 点击“同步选中结果到素材库”。

扩展只同步标题、BV 号、作者、封面、来源链接，以及页面当前显示的播放/弹幕/时长等公开指标；不会因为同步候选项就自动下载视频。下载前仍需在 GameNarrator 中确认权利并通过平台导入流程完成。

项目没有采用 `bili-spider` 的连续 AV 号枚举和多线程抓取方式。该仓库的公开指标采集思路被改造成浏览器页面读取，从而避免为了补充指标再次访问 Bilibili 接口。

Cookie 不会写入日志或素材元数据。后端只保留当前平台域名的临时 Cookie，下载完成或一小时后删除。

## Bilibili 登录

GameNarrator 的“扫码登录”和“账号密码登录”都会打开 Bilibili 官方页面。账号、密码、短信验证码与扫码确认均直接由 Bilibili 处理，GameNarrator 不读取或保存这些内容。登录成功后，扩展只把当前 Bilibili 会话临时交给已连接的 GameNarrator；后端令牌在下载完成或一小时后删除。

首页推荐最多同步 30 项，十分钟内不会重复读取。点击候选记录的“确认权利并下载”后，应用才会调用现有 yt-dlp 下载流程。
